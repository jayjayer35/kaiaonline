Functionality

  • Tokens can be made using the token button, they're used to represent anything really.
  • CTRL + L-Click will allow you to modify that specific token.
  • The Tokens menu on the left will allow you to change the 'height' of a token relative to others.
  • Lines can be created with the line tool, use them as walls prob.
  • Erasing via the eraser tool will allow you to remove tokens and lines.
  • Grid lines can be toggled with the 'toggle grid lines' button, go figure.
  • You can change the background of the page, or the grid if you so please as well. Uses a file on your pc.

Info

  • Default scale is 70.
  • Default columns & rows are 20 & 10 respectively.
